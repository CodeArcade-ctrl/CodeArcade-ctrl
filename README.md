# CodeArcade

I build practical, privacy-friendly tools and open-source projects. My work spans **Home Assistant** and browser-based developer utilities. I welcome ideas, bug reports, and contributions.

Ik maak praktische, privacyvriendelijke tools en open-sourceprojecten voor **Home Assistant** en in de browser. Ideeën, bugmeldingen en bijdragen zijn welkom.

## Home Assistant

I also build focused integrations and themes for Home Assistant. Browse my [Home Assistant projects](https://github.com/CodeArcade-ctrl?tab=repositories&q=home-assistant) or explore these integrations:

- [Solar Self-Use](https://github.com/CodeArcade-ctrl/solar-self-use) — understand local solar self-consumption.
- [Battery Runtime Estimator](https://github.com/CodeArcade-ctrl/battery-runtime-estimator) — estimate remaining battery runtime.
- [Water Pulse Meter](https://github.com/CodeArcade-ctrl/water-pulse-meter) — turn meter pulses into water usage.
- [Tank Level Volume](https://github.com/CodeArcade-ctrl/tank-level-volume) — convert a tank sensor into usable volume.
- [Dewpoint Guard](https://github.com/CodeArcade-ctrl/dewpoint-guard) — keep an eye on condensation risk.
